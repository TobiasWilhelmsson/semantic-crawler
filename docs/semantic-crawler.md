# Semantic Crawler

Run `make setup` once and `make start` from the project root. Choose Offline sample in the UI; `make demo` and `make eval` remain optional CLI workflows. The review UI is at http://127.0.0.1:8091/semantic.

The bundled pages are synthetic. Live sources use operator-supplied endpoint settings and source instructions. Human approval gates delivery; approved payloads can be sent to an allowlisted HTTP endpoint.

See the README, reviewer handbook, and source-onboarding guide for full instructions.
